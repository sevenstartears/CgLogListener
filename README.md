# CgLogViewer

BlueCG のチャットログを見やすく表示する Windows デスクトップアプリです。  
リアルタイム監視を中心に、ログ閲覧、翻訳、Discord 通知、お食事タイマー、NPC 会話抽出を 1 つのツールで扱えます。

![CgLogViewer のメイン画面](docs/logViewer.png)

## 主な機能

- リアルタイム監視
  `Log` フォルダを監視し、最新のログをリアルタイムで表示します。
- ログ閲覧モード
  任意のログファイルを選んで内容を閲覧できます。
- 重複ログの自動集約
  近い時刻に流れた同一本文のログを 1 件にまとめて表示します。
- カテゴリ分類
  `通常 / パーティ / ギルド / NPC / システム / その他` に分類し、色分けとフィルターに対応しています。
- シンプルビュー
  軽量な別窓でログだけを見やすく表示できます。サイズ、位置、フォントサイズ、カード高さは保存されます。
- 翻訳
  ログカード単位で `翻訳 / 原文` を切り替えられます。`DeepL API Free`、`Google Cloud Translation`、`OpenAI API` に対応しています。
- ログ保存
  現在ビューに表示されているログを Unicode テキストで保存できます。
- Discord 通知
  通知条件に一致したログを Discord Webhook に直接送信できます。
- お食事タイマー
  料理後の 3 分クールダウンをキャラごとにカウントダウン表示します。
- NPC 会話抽出
  対象プロセスのメモリから NPC 会話を抽出して表示し、その場で翻訳、コピー、メインビューへの追加ができます。

## ログ表示の仕様

- 文字コードは `Big5` を前提に読み込みます。
- 最新ログが下に来る順で表示します。
- URL を含むログはクリックでブラウザを開けます。
- 各ログは仮想化描画しているため、大量ログでも重くなりにくい構成です。

## カテゴリ分類ルール

- `[家族]` または `[家族 ...]` で始まるログは `ギルド`
- `[GP]` で始まるログは `パーティ`
- `名前:` の形式で始まるログは `通常`
- システム文言に該当するログは `システム`
- どれにも当てはまらないものは `その他`
- NPC 会話抽出から追加したログは `NPC`

## お食事タイマー

次のような料理ログを検出すると、食べたキャラの 3 分クールダウンを開始します。

- `22:00:18 対象キャラ恢復了985魔力`
- `22:00:18 別キャラ替対象キャラ恢復了985點魔力`

お食事タイマー窓を開いていない間も内部では追跡を続けます。

## NPC 会話抽出

- `NPC会話抽出` 窓から対象の `bluecg.exe` プロセスを選択します。
- 会話内容はリアルタイムで更新されます。
- 表示中の会話は `翻訳`、`コピー`、`ログに追加` ができます。
- `ログに追加` した内容はメインビューに `NPC` カテゴリのログカードとして追加されます。
- 対象プロセスのメモリ読取が必要なため、必要に応じて管理者権限で起動します。

## 設定できる内容

- ゲームフォルダ
- リアルタイム監視時の表示件数
- 同一ログのまとめ秒数
- 通知時 SE
- Discord Webhook URL
- 翻訳プロバイダと API キー
- 標準通知ルールとカスタム通知キーワード

設定はアプリ内の `表示と通知の設定` から変更できます。

## 動作環境

- Windows
- `.NET Framework 4.6`
- BlueCG のログフォルダへアクセスできること

## ビルド

Visual Studio で `src/CgLogViewer.sln` を開いて `Debug` または `Release` でビルドしてください。  
NuGet 復元後、実行ファイルは `src/CgLogViewer/bin/Debug/CgLogViewer.exe` または `src/CgLogViewer/bin/Release/CgLogViewer.exe` に出力されます。

## 補足

- 設定はアプリと同じフォルダの `settings.ini` と関連ファイルに保存されます。
- Discord 通知は外部 notifier を使わず、アプリ本体から直接送信します。
- 配布用ファイル名は `CgLogViewer.exe` です。
